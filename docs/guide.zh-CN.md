# 爪影使用手册

[返回项目首页](../README.md)

每只猫用一张照片建立本机桌面宠物。控制面板可以关闭，猫会继续在其他应用的窗口上活动。菜单栏的爪印可以隐藏猫、重新打开面板，或在使用多台显示器时把猫叫到当前屏幕。

## 试玩

需要 macOS 14 或更新版本，以及 Swift 6 工具链。

```sh
Scripts/package-app.sh
open build/Pawture.app
```

第一次启动自带咪咪和宝宝。到「我的猫咪」可以更换照片、添加猫咪和调整性格。照片里的脸、四肢和轮廓越清楚，姿态定位越稳。程序把照片和角色设置保存在本机的 `~/Library/Application Support/DesktopCats`。

- 猫有自己喜欢的屏幕边角，醒着会侧卧张望，睡着后可以原地蜷上几分钟。靠近的同伴偶尔会挨在一起睡。在「季节作息」选择北半球、南半球或关闭；程序按本机月份轻微调整休息倾向，不请求定位，猫的性格仍起主要作用。
- 桌面上直接点猫可以摸它，按住猫身或名字拖动可以抱走它。不需要先打开面板或开启捣乱。松手的位置会成为这只猫在当前屏幕上的新休息点，重启后仍保留。右击猫选「让到屏幕另一边」也能腾出位置。猫身外的空白不拦点击，从文档中开始的拖选即使划过猫也不会把它抱走。菜单栏的「点击穿透桌面猫咪」可以临时把猫身上的点击也交给下方应用。
- 光标停稳后，猫偶尔会走到一旁用脸颊蹭一下。不按按钮轻轻划过，侧卧的猫会眯眼靠脸，仰躺的猫会轻收前爪；不必来回摩擦才能触发。两只猫共用主动拜访的冷却时间，舒服时才偶尔翻肚皮。
- 试试「蜷睡」：不按键，用光标沿着猫的背或脸颊缓缓抚过一小段。它会保持蜷姿，耳朵轻动、脸颊往上靠，发出一声轻哼。继续抚摸，它可能呼噜着睡回去、翻身露出肚皮，或醒来，前爪往前探，伸完懒腰再侧卧。面板里的猫也能直接摸，支持轻点或按住左键轻抚。面板的扬声器和菜单栏的「猫咪声音」都能静音。
- 初始为「陪伴」。想用鼠标当逗猫棒，切换到「捣乱」，在醒着的猫面前、身体外侧往返晃动两三次，再停一停。它可能先看、伏低，再扑到落点附近，也可能放弃。单向移动、按住按钮拖选文字、远处的鼠标都不会发起追扑。没有真实系统光标偏移或键盘干扰。
- 在「桌面活动」可以随时试演走路、侧卧、蜷睡、睡醒、蹭手和翻肚皮；面板试演不会改变性格或打开捣乱模式。
- 面板的「猫咪互动」可以试演「碰鼻蹭脸」和「挨着打盹」；切到「捣乱」还能试「轮流追跑」。平时两只猫也会自己发起：凑近探鼻，对方有时会回蹭，有时会走开。已经熟睡的猫不会为给同伴让位而被叫醒。途中可以照常摸猫、抱走猫或让它让位；这些相遇不会改写你放好的休息点。

## 行为依据

[2024 年 AAFP 猫间关系指南](https://pmc.ncbi.nlm.nih.gov/articles/PMC11292941/)把鼻部接触、身体互蹭和贴着睡觉列为亲和行为。亲密不意味着每次都愿意接触，因此桌面猫也有不接邀约的时候。[2023 年双猫互动录像观察](https://www.nature.com/articles/s41598-022-26121-1)发现追逐本身不足以判定两只猫在玩。这里的玩法只让愿意参与的两只短追、停步、换角色；秒数与出现频率是为了桌面使用而设的，不是研究中的生理指标。

## 动作如何制作

Vision 从一张照片提取透明前景以及耳朵、鼻子、眼睛、腿和尾巴的位置。蹭手时脸颊先贴近，肩膀随后跟上；眼睛和口鼻一同转动，以保留五官比例。侧卧、蜷睡和翻身使用共享的二维身体结构，把原照的脸、毛纹和脚爪贴到重新摆放的部位上；腹部和肉垫的纹理由可见部位推算。动作在本机绘制和缓存，无需视频、云服务或多张姿势照。未拍到的花纹及体型可能与本猫不同。

```sh
swift run BehaviorChecks
sh Scripts/check-poses.sh
```

行为检查覆盖办公时的指针轨迹和不同性格的抚摸反应。姿态检查验证随朝向、姿态和宽高比变化后的命中位置，再从两张照片重新提取关节，输出 `build/preview/quiet-companions.png` 供肉眼对照。

改过桌面窗口或输入处理后，另用打包后的应用和一个空白文档检查实际事件投递：

1. 从猫旁边的文字开始拖选，经过猫再松手。选区应该连续，猫留在原位。
2. 从猫身上按住拖开。猫应跟手，文档没有新选区；松手后能直接点到它原先挡住的内容。
3. 在新位置轻点或慢摸猫，再右击选择「让到屏幕另一边」。它应该有所回应，并给当前工作区腾出位置。
