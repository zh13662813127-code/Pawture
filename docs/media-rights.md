你导入应用的照片仅保存在自己的 Mac 上；使用本项目不会将其公开，也不会将照片授权给项目。

介绍片《给它留一个熟悉的日常》使用爪影的示例猫、实际动作渲染、桌面浮层、控制面板与项目 README 画面。普通话解说采用 MiniMax 的青年男声；猫的轻哼来自应用本身，并非从照片还原的原声。制作解说只使用文字稿，不上传猫照。爪影应用本身不依赖配音服务。

早期短片《给想念的猫，在桌边留个位置》的普通话旁白由 [Kokoro-82M v1.1-zh](https://huggingface.co/hexgrad/Kokoro-82M-v1.1-zh) 在本机合成。旁白模型不随应用分发。
